# Spell <!-- help:notitle -->

**Орфография**

Проверяет орфографию текста с помощью aspell или hunspell и предлагает
варианты замены. Нужны библиотека движка и словарь языка.

|  |  |
|--|--|
| Ctrl-p | Проверить слово под курсором |

Весь файл проверяет пункт Орфография меню Плагины: проверка идет по словам и
останавливается на каждом, которого нет в словаре.

**Диалог проверки**

Показывает слово, варианты замены, язык и движок.

|  |  |
|--|--|
| Enter, Заменить | Заменить слово выбранным вариантом |
| Пропустить | Оставить слово как есть |
| Добавить | Добавить слово в личный словарь |
| Esc, Отмена | Остановить проверку |

**Настройки**

Диалог Управление плагинами меню Настройки задает движок, Aspell или
Hunspell, и язык: en, ru и другие имена, которые знает движок. Выбрать...
показывает установленные словари; у aspell их показывает и команда
*aspell dump dicts*. Язык NONE выключает проверку.

Настройки хранятся в секции *[EditorPluginSpell]* файла
*~/.config/bluerig/ini* (ключи *engine* и *language*). Клавиши задает
*spell.keymap* из системного каталога настроек bluerig, а
*~/.config/bluerig/spell.keymap* переопределяет их.
