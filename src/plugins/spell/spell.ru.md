# Spell <!-- help:notitle -->

**Орфография**

Плагин для проверки орфографии с помощью Aspell или Hunspell. Нужны
библиотека движка и словарь языка.

|  |  |
|--|--|
| Ctrl-P | Проверить слово под курсором |

Пункт Орфография в меню Плагины проверяет файл по словам и останавливается
на каждом слове, которого нет в словаре. Проверка идёт с начала файла;
только если курсор на первой строке, она начинается с позиции курсора.
В режиме *-D* меню Плагины нет, а у команды SpellCheck нет клавиши по
умолчанию: назначьте её в *spell.keymap*, например
*SpellCheck = ctrl-alt-o*.

**Диалог проверки**

Диалог показывает слово, варианты замены, язык и движок. Кнопка Заменить
доступна, когда есть хотя бы один вариант.

|  |  |
|--|--|
| Enter, Заменить | Заменить слово выбранным вариантом |
| Пропустить | Оставить слово как есть |
| Добавить | Открыть поле для ввода слова, которое нужно добавить |
| Esc, Отмена | Остановить проверку |

Aspell сохраняет добавленное слово в личном словаре. Hunspell хранит его
в памяти до перезапуска движка.

**Настройки**

Диалог Управление плагинами меню Настройки задаёт движок, Aspell или
Hunspell, и язык: en, ru и другие имена, которые знает движок. Кнопка
Выбрать... показывает установленные словари; у Aspell их показывает и команда
*aspell dump dicts*. Язык NONE выключает проверку.

Настройки хранятся в секции *[EditorPluginSpell]* файла
*~/.config/bluerig/ini* (ключи *engine* и *language*).

Плагин читает *spell.keymap* сначала из каталога данных bluerig, затем
из системного каталога настроек и из *~/.config/bluerig/spell.keymap*.
Пользовательский файл добавляет привязки. Если одна клавиша указана
несколько раз, действует первая найденная привязка.
