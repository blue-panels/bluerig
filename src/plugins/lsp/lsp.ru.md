# LSP <!-- help:notitle -->

**Языковые серверы**

Подключает языковые серверы для автодополнения, перехода к определениям
и поиска ссылок. Показывает диагностику, документацию и параметры вызова.
Языковые серверы устанавливаются отдельно:
clangd для C и C++, pylsp или pyright для Python, rust-analyzer для Rust,
gopls для Go и другие.

|  |  |
|--|--|
| Ctrl-Space | Дополнить слово |
| Alt-. | К определению имени под курсором |
| Ctrl-щелчок | К определению имени под указателем |
| Alt-> | К прототипу функции или объявлению имени |
| Alt-, | Документация имени под курсором |
| Alt-( | Параметры вызова |

Клавиши можно переназначить в секции *[lsp]* файла *~/.config/bluerig/keymap.ini*. В
файле, который не обслуживает ни один сервер, эти клавиши принадлежат
редактору.
Ctrl-Enter и Alt-g плагина Ctags (переход к определению и поиск ссылок)
сначала спрашивают языковой сервер, если он это умеет.

**Запуск сервера**

По умолчанию сервер запускается при открытии подходящего файла в режимах
*-D* и *-Q*. Вручную его запускает пункт Start server в меню LSP. Опция
*autostart* задаёт, когда запускать сервер, для всех серверов или для одного.

Все файлы одного проекта обслуживает один запущенный сервер. Для файла внутри проекта, открытого через *-D*, используется
корень этого проекта. В остальных случаях плагин ищет вверх по каталогам
*.bluerig*, затем маркеры из *root_markers* (например,
*compile_commands.json* для clangd), затем корень репозитория. Если корень
не найден и включён *single_file*, используется каталог файла.

Сервер без открытых файлов останавливается через минуту. Упавший сервер
перезапускается, но не больше трёх раз в минуту.

**Дополнение**

Варианты появляются под словом. Набранные буквы добавляются к слову и
фильтруют список: *mkg* находит *make_global*. Опция
*completion_on_trigger* включает автоматическое дополнение при наборе
слова и после символов, которые объявил сервер, например точки, *->* и *::*.

|  |  |
|--|--|
| Up, Down, PgUp, PgDn | Выбрать элемент |
| Enter, Tab | Вставить элемент |
| ., ->, :: | Вставить элемент и показать его члены |
| Esc | Закрыть список |

Функция вставляется со скобками, курсор встаёт внутри них, и над строкой
появляются параметры вызова. Вместе с элементом сервер может добавить
include; одна отмена убирает всё сразу.

Символ слева обозначает тип элемента:

|  |  |
|--|--|
| f, m | Поле, метод |
| F, v | Функция, переменная |
| C, S | Класс, структура |
| T | Параметр типа |
| # | Константа |
| k | Ключевое слово |

**Документация и параметры**

Alt-, показывает в рамке под курсором тип и документацию имени, ниже
сообщений о проблемах этой строки. Повторное Alt-, включает прокрутку
стрелками; Esc или движение курсора убирают рамку.

Alt-( показывает в рамке над строкой сигнатуру вызова и выделяет текущий
параметр, а под ней - описание параметра из комментария функции.
Подсказка появляется сама после *(* и *,*, если их объявил сервер. Это
включают опции *completion_on_trigger* и *completion_on_arguments*. Если
сигнатур несколько, Alt-Up и Alt-Down перебирают их.

**Проблемы**

Строки с проблемами отмечены слева: *E* - ошибка, *W* - предупреждение, *i* -
замечание. Пункт Problems... меню LSP открывает список сообщений всех
серверов. Если в текущем файле есть сообщения, выделяется первое из них.
Enter переходит к выбранному сообщению.

**Меню LSP**

|  |  |
|--|--|
| Start, Stop, Restart server | Запустить, остановить, перезапустить сервер файла |
| Status... | Серверы, их проекты и состояние |
| Log... | Вывод ошибок и сообщения сервера |
| Settings... | Настройки серверов |
| Project setup... | Настроить проект для clangd |

Project setup подбирает для clangd заголовки, которые нужно подключать
заранее, чтобы было меньше ложных ошибок, и предлагает исключить из индекса
каталоги тестов. Он проверяет до 400 заголовков; если их больше, берёт
выборку. Apply записывает результат в файл *.clangd* в корне проекта и
перезапускает сервер.

Settings записывает в *~/.config/bluerig/lsp.json* только то, что
отличается от системных настроек. Его же открывает кнопка Configure в
Управлении плагинами.

**lsp.json**

Серверы берутся из */etc/bluerig/lsp.json* и *~/.config/bluerig/lsp.json*.
Сервер из файла пользователя заменяет сервер с тем же id. Файл читается
при запуске bluerig и после записи диалогом настроек.

```
{
  "autostart": "always",
  "backends": [
    {
      "id": "clangd",
      "command": ["clangd", "--background-index",
                  "--compile-commands-dir=${build_dir}"],
      "extensions": {".c": "c", ".h": "c", ".cpp": "cpp"},
      "root_markers": ["compile_commands.json"]
    }
  ]
}
```

|  |  |
|--|--|
| autostart | ide (по умолчанию, только с -D и -Q), always или never |
| completion_on_trigger | Автодополнение при наборе слова и после последовательностей сервера: ide (по умолчанию), always или never |
| completion_on_arguments | Список дополнения после ( и ,: never (по умолчанию), ide или always |
| command | Программа и аргументы; ${build_dir} - каталог сборки проекта |
| extensions | Окончания имён файлов и их язык |
| root_markers | Файлы, которые отмечают корень проекта |
| single_file | Обслуживать файлы вне проекта; по умолчанию true |
| enabled | false выключает сервер |
| environment | Переменные окружения; null убирает переменную |
| initialization_options | Параметры, которые сервер получает при инициализации |
| settings | Настройки, которые сервер запрашивает |
| startup | query: сервер работает только с -Q |
| requests | Свои запросы после запуска: method и params |
| words | Дополнительные слова для списка дополнения |
| ascii_text | sql: заменять не-ASCII символы подчёркиванием |

*ascii_text* нужен серверу, который теряет позицию после не-ASCII символов,
например *postgres-language-server* 0.28.

В *requests* *${env:NAME}* - это переменная окружения, *${command_dir}* -
каталог программы сервера.

Сервер *mongolsp* дополняет запросы MongoDB в *bluerig -Q*. Это сервер
расширения MongoDB для VS Code (<https://github.com/blue-panels/mongolsp>),
он должен быть в PATH; строку подключения он получает из *MC_MONGO_URI*.
