# LSP <!-- help:notitle -->

**Языковые серверы**

Запускает языковые серверы и спрашивает их о коде: показывает ошибки,
дополняет слова, переходит к определениям, показывает документацию и
параметры вызова. Серверы - отдельные программы, их нужно установить:
clangd для C и C++, pylsp или pyright для Python, rust-analyzer, gopls и
другие.

|  |  |
|--|--|
| Ctrl-Space | Дополнить слово |
| Alt-. | К определению имени под курсором |
| Ctrl-щелчок | К определению имени под мышью |
| Alt-> | К прототипу функции или объявлению имени |
| Alt-, | Документация имени под курсором |
| Alt-( | Параметры вызова |

Клавиши меняются в секции *[lsp]* файла привязок клавиш. В файле, который
не обслуживает ни один сервер, эти клавиши принадлежат редактору. Команды
ctags в меню Навигация (Ctrl-Enter, Alt-g и другие) сначала спрашивают
сервер.

**Когда работает сервер**

Сервер запускается сам при открытии файла, если bluerig запущен на проекте
с *-D*, иначе - пунктом Start server меню LSP. Один сервер обслуживает все
файлы проекта: каталога с *.bluerig*, иначе ближайшего каталога с файлом,
который называет сервер (например, *compile_commands.json* для clangd),
иначе корня репозитория. Сервер без открытых файлов останавливается через
минуту. Упавший сервер перезапускается, но не больше трех раз в минуту.

**Дополнение**

Список стоит под словом, а набранные буквы продолжают слово и сужают
список: *mkg* находит *make_global*. На проекте *-D* список появляется сам
при наборе слова и после точки, *->* и *::*.

|  |  |
|--|--|
| Up, Down, PgUp, PgDn | Выбрать элемент |
| Enter, Tab | Вставить элемент |
| ., ->, :: | Вставить элемент и показать его члены |
| Esc | Закрыть список |

Функция вставляется со скобками, курсор встает внутри них, и над строкой
появляются параметры вызова. Вместе с элементом сервер может добавить
include; одна отмена убирает все сразу.

Буква слева говорит, что это за элемент:

|  |  |
|--|--|
| f, m | Поле, метод |
| F, v | Функция, переменная |
| C, S | Класс, структура |
| T | Параметр типа |
| # | Константа |
| k | Ключевое слово |

**Документация и параметры**

Alt-, показывает в рамке под курсором тип и документацию имени, после
проблем строки. Повторное Alt-, включает прокрутку стрелками; Esc или
движение курсора убирают рамку.

Alt-( показывает в рамке над строкой сигнатуру вызова и выделяет текущий
параметр, а под ней - описание параметра из комментария функции. На проекте
*-D* рамка появляется сама после *(* и *,*. Если сигнатур несколько, Alt-Up
и Alt-Down перебирают их.

**Проблемы**

Строки с проблемами отмечены слева: *E* - ошибка, *W* - предупреждение, *i* -
замечание. Пункт Problems... меню LSP показывает их списком, Enter переходит
к выбранной.

**Меню LSP**

|  |  |
|--|--|
| Start, Stop, Restart server | Запустить, остановить, перезапустить сервер файла |
| Status... | Серверы, их проекты и состояние |
| Log... | Вывод ошибок и сообщения сервера |
| Settings... | Настройки серверов |
| Project setup... | Настроить проект для clangd |

Project setup проверяет каждый заголовочный файл отдельно, как его читает
clangd, находит заголовки, без которых он дает ошибки, и предлагает
исключить каталоги тестов из индекса. Apply записывает это в блок
*.clangd* в корне проекта и перезапускает сервер.

Settings записывает в *~/.config/bluerig/lsp.json* только то, что
отличается от системных настроек. Тот же диалог открывает Configure в
диалоге Управление плагинами.

**lsp.json**

Серверы берутся из */etc/bluerig/lsp.json* и *~/.config/bluerig/lsp.json*.
Сервер из файла пользователя заменяет сервер с тем же id.

```
{
  "autostart": "always",
  "backends": [
    {
      "id": "clangd",
      "command": ["clangd", "--background-index",
                  "--compile-commands-dir=${build_dir}"],
      "extensions": {".c": "c", ".h": "c", ".cpp": "cpp"},
      "root_markers": ["compile_commands.json"]
    }
  ]
}
```

|  |  |
|--|--|
| autostart | ide (по умолчанию, только с -D и -Q), always или never |
| completion_on_trigger | Список после точки, -> и :: сам: ide, always или never |
| completion_on_arguments | Список после ( и , сам: never (по умолчанию), ide, always |
| command | Программа и аргументы; ${build_dir} - каталог сборки проекта |
| extensions | Окончания имен файлов и их язык |
| root_markers | Файлы, которые отмечают корень проекта |
| single_file | Обслуживать файлы вне проекта; по умолчанию true |
| enabled | false выключает сервер |
| environment | Переменные окружения; null убирает переменную |
| initialization_options | Что сервер получает при запуске |
| settings | Настройки, которые сервер запрашивает |
| startup | query: сервер работает только с -Q |
| requests | Свои запросы после запуска: method и params |
| words | Дополнительные слова для списка дополнения |
| ascii_text | sql: заменять не-ASCII символы подчеркиванием |

*ascii_text* нужен серверу, который теряет позицию после не-ASCII символов,
например *postgres-language-server* 0.28. В *requests* *${env:NAME}* - это
переменная окружения, *${command_dir}* - каталог программы сервера.

Сервер *mongolsp* дополняет запросы MongoDB в *bluerig -Q*. Это сервер
расширения MongoDB для VS Code (<https://github.com/blue-panels/mongolsp>),
он должен быть в PATH; строку подключения он получает из *MC_MONGO_URI*.

Файл читается при запуске bluerig и после записи диалогом настроек.
