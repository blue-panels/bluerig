# Definitions <!-- help:notitle --><a id="definitions"></a>

**Список определений**

Показывает определения имени под курсором, найденные в файле тегов: файл,
номер строки и текст строки каждого.

|  |  |
|--|--|
| Enter | Перейти к определению |
| Esc | Закрыть список |

Список появляется, только когда определений несколько; к единственному
редактор переходит сразу.

|  |  |
|--|--|
| Alt-Enter | Найти определения имени, в конце которого стоит курсор |
| Alt-Minus | Назад по местам переходов |
| Alt-Plus | Вперед |

Определения берутся из файла *TAGS* в формате Emacs, который ищется в
текущем каталоге и выше. Его строит etags или ctags:

```
etags -R .
ctags -e -R .
```
