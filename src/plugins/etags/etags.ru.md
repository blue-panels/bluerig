# Definitions <!-- help:notitle --><a id="definitions"></a>

**Список определений**

Показывает найденные в файле тегов определения имени. Для каждого
показаны имя тега или фрагмент записи из *TAGS*, имя файла и номер строки.

|  |  |
|--|--|
| Enter | Перейти к определению |
| Esc | Закрыть список |

Список открывается и при одном найденном определении. Для перехода
нажмите Enter.

|  |  |
|--|--|
| Alt-Enter | Найти определения имени, в конце которого стоит курсор |
| Alt-Minus | Назад по местам переходов |
| Alt-Plus | Вперед |

Плагин ищет файл *TAGS* в формате Emacs, начиная с текущего рабочего
каталога и поднимаясь по родительским каталогам. Используется первый
найденный файл, даже если в нём нет совпадений. Файл строит etags или ctags:

```
etags -R .
ctags -e -R .
```
