# Coverage <!-- help:notitle -->

**Покрытие**

Отмечает на полях строки, которые выполнились при запуске тестов или
программы, и строки с кодом, который не выполнился. Работает в
*bluerig -D*.

|  |  |
|--|--|
| Project > Show/hide coverage | Показать или убрать метки покрытия |
| Project > Reread coverage | Перечитать данные покрытия сейчас |

Выполненная строка отмечается зеленой полосой, невыполненная - желтой.
Строки без кода, комментарии и пустые строки остаются без метки. Метки
двигаются вместе со строками при правке, до следующего чтения данных.

**Откуда берутся данные**

|  |  |
|--|--|
| gcov | файлы *.gcda* в каталоге сборки meson или cmake, иначе в корне проекта |
| lcov | *coverage.info*, *lcov.info* или *coverage/lcov.info* в корне проекта, *meson-logs/coverage.info* в каталоге сборки |

Файлы *.gcda* появляются, когда собранная с *-Db_coverage=true* (meson) или
с *--coverage* (gcc, clang) программа завершается. Если их нет, читается
первый найденный файл lcov: его пишут *coverage lcov* для Python, *cargo
llvm-cov --lcov* для Rust, *c8* и *nyc* для JavaScript.

gcov и чтение файлов идут в отдельном процессе, метки расставляются по
частям, пока редактор ничего не делает, поэтому редактор не замирает и на
большом проекте.

**Когда данные читаются снова**

Плагин перечитывает данные после сборки, после команды в окне терминала и
когда окно файла выходит на передний план, не чаще раза в две секунды. Если
файлы покрытия не изменились с прошлого чтения, gcov не запускается.

Символы меток задают ключи *coverage-covered-char* и
*coverage-missed-char* секции *[widget-editor]* скина, цвета -
*coveragecovered* и *coveragemissed* секции *[editor]*.
