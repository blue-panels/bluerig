# Coverage <!-- help:notitle -->

**Покрытие**

Показывает процент покрытия кода в дереве проекта. Метка слева от номера
строки показывает, выполнилась ли эта строка при запуске тестов или
программы. Работает в *bluerig -D*.

|  |  |
|--|--|
| Project > Show/hide coverage | Показать или убрать метки покрытия |
| Project > Reread coverage | Перечитать данные покрытия сейчас |

Покрытая тестами строка отмечается зелёной полосой, непокрытая - жёлтой.
Строки без кода, комментарии и пустые строки остаются без метки. Метки
двигаются вместе со строками при правке, до следующего чтения данных.
Дерево проекта показывает после каждого файла долю его выполненных строк
кода, *83%*, а после каталога - долю всех его файлов вместе.

**Откуда берутся данные**

|  |  |
|--|--|
| gcov | файлы *.gcda* в каталоге сборки профиля покрытия, иначе в каталоге сборки meson или cmake, иначе в корне проекта |
| lcov | *coverage.info*, *lcov.info* или *coverage/lcov.info* в корне проекта, *meson-logs/coverage.info* в каталоге сборки |

Профиль покрытия - это профиль сборки, см. Build profiles в справке плагина
Build: созданный плагином, иначе активный профиль, если он собирает с
покрытием, иначе первый такой профиль. Без данных плагин предлагает
создать его из активного профиля с *-Db_coverage=true* и запуском тестов
после сборки, в своем каталоге: открывается окно профиля, а после
сохранения плагин предлагает собрать его и запустить тесты. Если профиль
уже есть, плагин предлагает собрать его и запустить тесты.

Файлы *.gcda* появляются, когда собранная с *-Db_coverage=true* (meson) или
с *--coverage* (gcc, clang) программа завершается. Если их нет, читается
первый найденный файл lcov: его пишут *coverage lcov* для Python, *cargo
llvm-cov --lcov* для Rust, *c8* и *nyc* для JavaScript.

gcov и чтение файлов идут в отдельном процессе, метки расставляются по
частям, пока редактор ничего не делает, поэтому редактор не замирает и на
большом проекте.

**Когда данные читаются снова**

Плагин перечитывает данные после сборки профиля покрытия, но не другого
профиля, после команды в окне терминала и когда окно файла выходит на
передний план, не чаще раза в две секунды. Если
файлы покрытия не изменились с прошлого чтения, gcov не запускается.

Символы меток задают ключи *coverage-covered-char* и
*coverage-missed-char* секции *[widget-editor]* скина, цвета -
*coveragecovered* и *coveragemissed* секции *[editor]*.
