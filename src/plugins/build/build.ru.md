# Build <!-- help:notitle -->

**Сборщик**

Собирает проект, показывает вывод компилятора списком ошибок и переходит к
строкам с ошибками и предупреждениями.

|  |  |
|--|--|
| Ctrl-F9, Alt-B | Собрать проект |
| Alt-J | К следующей ошибке |
| Alt-K | К предыдущей ошибке |
| Enter | В списке ошибок: перейти к ошибке |

Клавиши меняются в секции *[build]* файла привязок клавиш. Те же команды
есть в меню Project.

Перед сборкой сохраняет измененные файлы проекта. Вывод компилятора
появляется в окне **Сборщик** внизу экрана; Project > Build output снова
показывает это окно. Alt-J
переходит к предупреждениям, когда ошибок нет.

**Список ошибок**

После сборки окно показывает результат, затем ошибки и предупреждения по
строке на каждое, с примечаниями под ними, и в конце остальной вывод
компилятора. Курсор списка следует за Alt-J и Alt-K. Когда курсор
двигается по списку, строка ошибки показывается в ее файле, если файл
открыт; Enter или двойной щелчок переходит к ней. Курсор встает в колонку,
которую назвал компилятор.

Строки с ошибками отмечаются на полях крестиком, с предупреждениями -
восклицательным знаком, до следующей сборки. Символы меток задают ключи
*build-error-char* и *build-warning-char* секции *[widget-editor]* скина,
цвета - *builderror* и *buildwarning* секции *[editor]*.

**Как собирается проект**

Плагин сам находит, чем собирать проект:

|  |  |
|--|--|
| meson | meson compile -C с каталогом сборки meson этого проекта |
| cmake | cmake --build с каталогом сборки cmake |
| make | make, если в проекте есть Makefile |
| язык | команда языка проекта из presets.ini, например cargo build или go build ./... |

Каталог сборки и способ его собрать составляют профиль сборки, см.
[Профили сборки](#build-profiles). Ctrl-F9 собирает активный. Найденный
первым профиль называется *Default*; заданная в нем своя команда идет раньше
найденной. Если ничего не найдено, плагин спрашивает команду при первой
сборке.

**Языки и настройки проекта**

Файл *presets.ini* из каталога настроек bluerig описывает языки: маркеры в
корне проекта, расширения файлов, команду сборки и способ отладки. Файл
*~/.config/bluerig/presets.ini* дополняет его, и его группа заменяет
одноименную группу bluerig целиком.

Проект, открытый через *bluerig -D* или Project > Open project..., получает
копию настроек своего языка в *.bluerig/project.ini*, при этом изменения в
ней остаются за проектом. Ключ, которого нет в копии, плагин берет из
*presets.ini*. Project > Language defaults of the project... заново
делает копию из настроек языка.

# Профили сборки <a id="build-profiles"></a>

Project > Build profiles... показывает профили проекта: имя, каталог сборки,
систему сборки и то, для чего каталог собран (debug, coverage,
address,undefined). Активный профиль отмечен *\**: его собирает Ctrl-F9, и
отладчик запускает собранные им программы. Профиль make собирает в дереве
исходников: созданный из него профиль собирает там же, и список говорит, что
он делит дерево с другим.

**Space**
: Сделать профиль под курсором активным. Enter делает то же и закрывает
окно.

**Ins**
: Новый профиль из профиля под курсором: с его опциями и командами, в своем
каталоге рядом с его каталогом; открывается в своем окне. Первая сборка
настраивает новый каталог.

**F4**
: Окно профиля, см. [Профиль сборки](#build-profile).

**F5**
: Собрать профиль, активный остается прежним.

**Del**
: Удалить профиль. Каталог сборки остается.

Профили хранятся в настройках пользователя, а не в проекте:
*~/.config/bluerig/build/*, по файлу на проект.

# Профиль сборки <a id="build-profile"></a>

Окно профиля: сверху поля, под ними опции его каталога сборки. Tab
переходит между полями и опциями; строка под опциями говорит, что это за
поле или опция под курсором.

**Name**
: Имя профиля, без *[* и *]*.

**Directory**
: Каталог сборки, от корня проекта (*../coole-build*, *build/debug*) или
абсолютный. Еще не настроенный каталог настраивает F2 или первая сборка, с
опциями профиля.

**Build command**
: Команда, которая собирает профиль, запускается в корне проекта. Пустая -
команда системы сборки: *meson compile -C* или *cmake --build* с каталогом,
перед ней настройка, если каталог еще не настроен. Оставьте ее пустой, если
профиль не собирается как-то иначе.

**Test command**
: Команда, которая запускает тесты, запускается в корне проекта: *meson
test -C* или *ctest --test-dir* с каталогом. Пустая - тестов нет.

**Run the tests after the build**
: Ctrl-F9 запускает команду тестов после сборки. Покрытие тестами берется из
сборки с *b_coverage* и запущенных тестов: *b_coverage*, ставшая *true*,
отмечает флажок и заполняет пустую команду тестов.

Опции каталога, meson или cmake, показаны со значением и умолчанием;
значение, отличное от умолчания, выделено цветом. На рамке видно, что с
каталогом: еще не настроен, изменен, применен.

**Del**
: Отменить изменение опции под курсором.

**F2**
: Сохранить профиль и применить изменения: *meson configure* с ними или
*meson setup* со всеми опциями профиля, если каталог еще не настроен; у
cmake так же. Вывод идет в окно Build, окно профиля остается. Затем опции
заново читаются из каталога.

**F3**
: Показать по очереди основные опции, отличные от умолчания или все.
Основные - заданные пользователем, опции проекта и те, что говорят, для
чего сборка.

**F4**
: Изменить опцию под курсором: логическая принимает другое значение, опция
с вариантами берет один из списка, остальные вводятся. Непримененное
изменение отмечено *\** перед именем.

**Enter**
: Сохранить профиль и применить изменения опций, затем закрыть окно; в
полях и в опциях одинаково.

**Esc**
: Закрыть окно; про несохраненное спрашивается.

Набранные в опциях буквы фильтруют их имена.
