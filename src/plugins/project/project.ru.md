# Project <!-- help:notitle -->

**Файлы проекта**

Плагин для работы с файлами проекта: навигация и поиск.

|  |  |
|--|--|
| Alt-P | Открыть файл проекта |
| Ctrl-E | Последние файлы проекта |
| Alt-T | Открыть дерево проекта или перейти в него; из дерева - закрыть его |
| Alt-A | Перейти от исходного файла к заголовку и обратно |
| Alt-F7 | Найти текст в файлах проекта |

Клавиши можно переназначить в секции *[project]* файла *~/.config/bluerig/keymap.ini*.
Те же команды есть в меню Project, а Alt-A - в меню Навигация.

**Открыть файл проекта**

В диалоге сначала показан список недавних файлов проекта, а если их нет -
список файлов проекта, не больше 500. Ввод фильтрует список нечётким поиском
по всем файлам: остаются пути, в которых введённые символы идут по порядку.
Enter открывает выбранный файл. Поддерживаются также запросы:

|  |  |
|--|--|
| edwi | Файлы, в пути которых эти буквы идут по порядку: *src/editor/editwidget.c* |
| main:42 | Файл *main* на строке 42 |
| :42 | Строка 42 последнего открытого файла |
| @divi | Функции, типы и переменные проекта с этими буквами в имени |
| calc@ | Символы файла *calc*; *calc@tw* - только те, где есть *tw* |

Символы берёт плагин Ctags, без него запросы с @ не работают.

**Найти в проекте**

Поиск идёт по мере набора, начиная со второго символа, без регулярных
выражений: находятся строки, содержащие введённый текст. Если в запросе нет
заглавных букв, регистр не учитывается. Под списком отображается фрагмент
файла вокруг выбранной строки. В списке не больше 5000 строк. Просматриваются
файлы проекта: в git-репозитории - отслеживаемые и не игнорируемые через
*.gitignore*, без git - все, кроме скрытых, каталогов сборки и
*node_modules*. Двоичные файлы и каталог *.bluerig* пропускаются всегда.

|  |  |
|--|--|
| Up, Down, PgUp, PgDn | Выбрать строку |
| Enter | Перейти к строке |
| Esc | Закрыть поиск |

**Дерево проекта**

Показывает каталоги и файлы проекта. Для активного файла доступно
отображение его функций, типов и переменных; их находит плагин Ctags.
Для файлов больше 1 МиБ список символов не строится. Файл в активном окне
и символ под курсором выделены жирным. Справа от имени файла указано
число строк, у больших и двоичных файлов указан размер. При включённом
покрытии рядом с числом строк или размером показан процент покрытия,
например *83%*. Для каталога показан общий процент по данным его файлов.

|  |  |
|--|--|
| Enter | Открыть файл, перейти к строке символа, раскрыть или свернуть каталог |
| Right, Left | Раскрыть или свернуть каталог или символы файла |
| Буква | Перейти к следующему имени на эту букву |
| Esc, F10 | Закрыть дерево |

Метки перед именами задаёт секция *[project]* скина, а соответствие имён и
меток - файл *project-marks.ini*; файл *~/.config/bluerig/project-marks.ini*
дополняет его.

**Какой каталог считается проектом**

При автоматическом выборе корня плагин поднимается от каталога открытого
файла. Поиск идёт до домашнего каталога, если он лежит на пути, или до корня
файловой системы. Плагин выбирает ближайший каталог с *.bluerig* или *.git*.
Если таких каталогов нет, выбирает самый верхний каталог с маркером проекта,
например *meson.build*, *CMakeLists.txt*, *Makefile*, *Cargo.toml*, *go.mod*
или *package.json*. Если маркеров нет, использует каталог файла и показывает
файлы только из него.

Project > Open project... выбирает другой проект, Project > Close project
закрывает его.

В Git-проекте список включает отслеживаемые файлы и неотслеживаемые
файлы, которые Git не игнорирует. При обходе каталогов плагин пропускает
скрытые файлы и каталоги, каталоги сборки и ссылки на каталоги.
