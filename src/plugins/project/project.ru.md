# Project <!-- help:notitle -->

**Файлы проекта**

Открывает файлы проекта по нескольким буквам имени, ищет текст во всех его
файлах и показывает дерево проекта у левого края экрана.

|  |  |
|--|--|
| Alt-P | Открыть файл проекта |
| Ctrl-e | Последние файлы проекта |
| Alt-T | Показать или скрыть дерево проекта |
| Alt-A | Перейти от исходного файла к заголовку и обратно |
| Alt-F7 | Найти текст в файлах проекта |

Клавиши меняются в секции *[project]* файла привязок клавиш. Те же команды
есть в меню Project, а Alt-A - в меню Навигация.

**Открыть файл проекта**

Показывает последние файлы проекта, а по мере набора - файлы, в имени которых
есть набранные буквы по порядку. Строка понимает и другие запросы:

|  |  |
|--|--|
| edwi | Файлы с этими буквами в имени: *src/editor/editwidget.c* |
| main:42 | Файл *main* на строке 42 |
| :42 | Строка 42 текущего файла |
| @divi | Функции, типы и переменные проекта с этими буквами в имени |
| calc@ | Символы файла *calc*; *calc@tw* - только те, где есть *tw* |

Символы берет плагин Ctags, без него запросы с @ не работают.

**Найти в проекте**

Ищет текст по мере набора, начиная со второй буквы, и показывает найденные
строки, а под ними - файл вокруг выбранной строки. Текст без заглавных букв
ищется без учета регистра. Показывает не больше 5000 строк, двоичные файлы
пропускает.

|  |  |
|--|--|
| Up, Down, PgUp, PgDn | Выбрать строку |
| Enter | Перейти к строке |
| Esc | Закрыть поиск |

**Дерево проекта**

Показывает каталоги и файлы проекта, а под файлом переднего окна - его
функции, типы и переменные. Файл переднего окна и символ под курсором
выделены жирным. Справа от файла стоит число его строк, у больших и двоичных
файлов - размер.

|  |  |
|--|--|
| Enter | Открыть файл, раскрыть или свернуть каталог |
| Right, Left | Раскрыть или свернуть каталог или символы файла |
| Буква | Перейти к следующему имени на эту букву |
| Esc, F10 | Закрыть дерево |

Метки перед именами задает секция *[project]* скина, а какое имя чем считать -
файл *project-marks.ini*. Файл *~/.config/bluerig/project-marks.ini*
дополняет его.

**Какой каталог считается проектом**

Проект определяется по первому открытому файлу: это ближайший каталог над
ним, в котором есть *.bluerig* или *.git*, иначе самый верхний каталог с
файлом сборки (*meson.build*, *CMakeLists.txt*, *Makefile*), но не выше
домашнего. Project > Open project... выбирает другой проект, Project > Close
project закрывает его. В файлы проекта входит то, что знает git, иначе все,
кроме скрытых каталогов и каталогов сборки.
