# Ctags <!-- help:notitle -->

**Ctags**

Переходит к определениям имен и находит места, где имя используется, по
индексу, который строит ctags.

|  |  |
|--|--|
| Ctrl-Enter | К определению имени под курсором |
| Ctrl-щелчок | К определению имени под мышью |
| Ctrl-Backslash | Найти определение по имени |
| Alt-g | Найти ссылки на имя под курсором |
| Alt-Minus | Назад, к месту перед переходом |
| Alt-Plus | Вперед |
| Alt-h | История переходов |
| Alt-= | Члены класса или структуры |
| Alt-q | Найти символ проекта |
| Alt-y | Символы текущего файла |
| Shift-Tab | Дополнить символ перед курсором |

Если у имени несколько определений, показывает их список. В файле, который
обслуживает языковой сервер, Ctrl-Enter и Alt-g сначала спрашивают сервер, а
Ctrl-щелчок обрабатывает сам сервер. Alt-Minus и Alt-Plus учитывают и
переходы языкового сервера. История переходов живет, пока работает редактор.

Те же команды есть в меню Навигация. Меню Ctags в меню Плагины добавляет
поиск файла, загрузку файла тегов, переиндексацию и список репозиториев.

**Индекс**

Строит индекс проекта сам, в фоне, при первой команде в файле проекта, а при
запуске *bluerig -D* - сразу. Хранит его в *.bluerig/tags* проекта и
обновляет после каждого сохранения файла проекта. Файл *tags* в корне
проекта не перестраивает, а берет как есть. Без проекта ищет *tags* в
каталоге файла и выше.

Нужна программа ctags, лучше Universal Ctags (пакет universal-ctags).
Параметры ctags для проекта задаются в форме Debug configuration отладчика.

**Настройки**

Секция *[ctags]* файла *~/.config/bluerig/ini* хранит команду ctags, ее
параметры, учет регистра при поиске и автоматический поиск файла тегов. Их
меняет диалог Управление плагинами меню Настройки.

Клавиши задает *ctags.keymap* из системного каталога настроек bluerig, а
*~/.config/bluerig/ctags.keymap* переопределяет их.
