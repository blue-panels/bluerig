# Ctags <!-- help:notitle -->

**Ctags**

Переходит к определениям по индексу ctags. Для поиска ссылок проверяет,
есть ли имя в индексе, затем ищет его с помощью grep в индексированных файлах.

|  |  |
|--|--|
| Ctrl-Enter | К определению имени под курсором |
| Ctrl-щелчок | К определению имени под указателем |
| Ctrl-Backslash | Найти определение по имени |
| Alt-g | Найти ссылки на имя под курсором |
| Alt-Minus | Назад, к месту перед переходом |
| Alt-Plus | Вперед |
| Alt-h | История переходов |
| Alt-= | Члены класса или структуры |
| Alt-q | Найти символ проекта |
| Alt-y | Символы текущего файла |
| Shift-Tab | Дополнить символ перед курсором |

Если у имени несколько определений, показывает их список. Ctrl-Enter,
Ctrl-щелчок и Alt-g сначала обращаются к языковому серверу, если он
поддерживает этот запрос. Если плагин LSP не берёт запрос, используется
Ctags. Alt-Minus и Alt-Plus учитывают и переходы языкового сервера.
История переходов хранится до выхода из редактора.

Те же команды есть в меню Навигация. Меню Ctags в меню Плагины добавляет
поиск файла, загрузку файла тегов, переиндексацию и список репозиториев.

**Индекс**

Если включён автоматический поиск, плагин загружает индекс при первой
команде, которой он нужен. При запуске *bluerig -D* загружает его при
открытии файла. Если в корне проекта есть файл *tags*, плагин использует
его. Иначе строит собственный индекс в фоне и хранит его в
*.bluerig/tags*. Собственный индекс обновляется при сохранении или
переименовании файла проекта. Ручная переиндексация может перезаписать
файл *tags* в корне. Без проекта плагин ищет *tags* в каталоге файла и выше.

Нужна программа ctags, лучше Universal Ctags (пакет universal-ctags).
Параметры ctags для проекта задаются в форме Debug configuration отладчика.

**Настройки**

Секция *[ctags]* файла *~/.config/bluerig/ini* хранит команду ctags, ее
параметры, учет регистра при поиске и автоматический поиск файла тегов. Их
можно изменить через Плагины > Ctags > Configuration.

Плагин читает *ctags.keymap* из каталога данных, затем из системного
каталога настроек. Пользовательский *~/.config/bluerig/ctags.keymap*
загружается последним и переопределяет привязки.
