# Preview <!-- help:notitle -->

**Предпросмотр**

Плагин для предпросмотра файлов, например Markdown, JSON и XML. Другие
форматы файлов можно добавить своим Lua-скриптом в каталоге
*~/.local/share/bluerig/lua/scripts/*, по образцу render-markdown,
render-json и render-xml. Как писать скрипты, описано в разделе
[Скрипты на Lua](bluerig.md#lua-scripting).

Окно предпросмотра обновляется при правке и прокручивается вслед за
курсором редактора.

|  |  |
|--|--|
| Ctrl-Alt-P | Показать или скрыть окно Предпросмотр |

Клавиша задаётся параметром *key* секции *[Preview]* файла
*~/.config/bluerig/viewer.ini*.
Тот же пункт есть в меню Плагины и в меню Окна. В режиме Git
(*bluerig -G*) клавиша и пункт Предпросмотр в меню Окна недоступны.

При открытии предпросмотра фокус остаётся в редакторе. При переходе
в другое окно редактора предпросмотр показывает файл из этого окна.
Предпросмотр можно перемещать, менять его размер и закрывать так же,
как окно файла.

**Клавиши в окне**

Когда фокус в окне, у него свой курсор:

|  |  |
|--|--|
| Клавиши курсора, Home, End | Двигать курсор |
| PgUp, PgDn | Страницу вверх, вниз |
| Ctrl-Home, Ctrl-End | К началу, к концу текста |
| Ctrl-Left, Ctrl-Right | На восемь столбцов влево, вправо |
| Щелчок | Поставить курсор |
| Перетаскивание мышью, Shift с клавишами движения | Выделить текст |
| F3 | Начать или завершить выделение |
| Ctrl-A | Выделить весь текст |
| Ctrl-Insert, Enter | Скопировать выделенное в файл обмена |
| Колесо мыши | Прокрутить, даже если фокус не в окне |
| Shift-колесо | Прокрутить вбок |

**Типы файлов**

Предпросмотр сначала определяет формат по окончанию имени файла.
Если не подошло, проверяет начало текста. Например, JSON
распознаётся по расширению, а XML также по началу `<?xml`. Если формат
распознать не удалось, показывает исходный текст.

|  |  |
|--|--|
| Markdown | Заголовки, списки, таблицы, блоки кода, формулы и диаграммы Mermaid |
| JSON, JSON Lines | Значение на строку, размеры объектов и массивов, однотипные объекты таблицей |
| XML | Элемент на строку, число вложенных элементов, однотипные элементы таблицей |

Из диаграмм Mermaid поддерживаются блок-схемы (`flowchart` и `graph`),
диаграммы последовательности (`sequenceDiagram`), диаграммы классов
(`classDiagram`) и круговые диаграммы (`pie`).

Настройки render-markdown задаёт диалог Управление плагинами,
они хранятся в
*~/.config/bluerig/render-markdown.ini*.

JSON и XML объёмом больше 16 МиБ показываются обычным текстом.

При ошибке разбора предпросмотр показывает её сообщение, строку и столбец.
Ниже остаётся последнее удачное представление. Если его ещё нет, показан
исходный текст.

Длинная строка base64 сокращается до первых символов, а рядом показывается,
что в ней: начало текста или тип файла, и размер.
