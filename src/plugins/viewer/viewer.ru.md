# Preview <!-- help:notitle -->

**Предпросмотр**

Показывает файл в окне справа от него так, как его задумано читать:
markdown с заголовками и таблицами, JSON и XML с отступами и цветами.
Перерисовывает вид по мере правки и следует за курсором.

|  |  |
|--|--|
| Ctrl-Alt-p | Показать или спрятать окно Предпросмотр |

Клавиша задается параметром *key* секции *[Preview]* файла *viewer.ini*.
Тот же пункт есть в меню Плагины и в меню Окна.

Фокус остается в файле, а окно показывает тот файл, который выходит
вперед. Окно двигают, меняют его размер и закрывают так же, как окно файла.

**Клавиши в окне**

Когда фокус в окне, у него свой курсор:

|  |  |
|--|--|
| Клавиши курсора, Home, End | Двигать курсор |
| PgUp, PgDn | Страницу вверх, вниз |
| Ctrl-Home, Ctrl-End | К началу, к концу текста |
| Ctrl-Left, Ctrl-Right | На восемь столбцов влево, вправо |
| Щелчок | Поставить курсор |
| Колесо мыши | Прокрутить, и без фокуса |
| Shift-колесо | Прокрутить вбок |

**Типы файлов**

Файл рисует рендер его типа, которого просмотрщик выбирает по окончанию
имени или по началу текста. Файл, которого не знает ни один рендер,
показывается как текст.

|  |  |
|--|--|
| Markdown | Заголовки, списки, таблицы, блоки кода, формулы и диаграммы mermaid |
| JSON, JSON Lines | Значение на строку, размеры объектов и массивов, однотипные объекты таблицей |
| XML | Элемент на строку, число вложенных элементов, однотипные элементы таблицей |

Рендеры - Lua-скрипты render-markdown, render-json и render-xml. Настройки
render-markdown задает диалог Управление плагинами, они хранятся в
*~/.config/bluerig/render-markdown.ini*.

Пока JSON или XML не читается, например посреди правки, сверху показана
ошибка и ее место, а под ней - последний удачный вид. Длинная строка base64
сокращается до первых букв, а рядом показывается, что в ней: начало текста
или тип файла, и размер.
