# Terminal <!-- help:notitle -->

**Терминал**

Запускает в окне редактора оболочку из переменной **SHELL**. Если
переменная не задана, используется оболочка входа пользователя, а если и её
нет - первая найденная в */bin*, например *bash* или *zsh*.
Оболочка запускается в каталоге редактируемого файла. Если файл не открыт
или каталог недоступен, используется рабочий каталог редактора.
Поддерживаются bash, zsh, fish, tcsh и другие оболочки.

**Ctrl-O**
: Показать окно терминала: в первый раз внизу экрана, потом таким, каким
оно было, когда его скрыли. Файл, показанный на весь экран, становится
окном над терминалом. Ctrl-O в терминале снова скрывает окно, и файл
опять занимает весь экран, если его за это время не двигали и не меняли
его размер. Оболочка продолжает работать, пока окно скрыто: то, что она
выводит в это время, видно, когда окно снова показано. Если окно на экране,
но под другим окном, Ctrl-O поднимает его наверх.

Окно терминала можно перемещать, менять его размер, разворачивать на весь
экран и закрывать кнопкой [X] на рамке. Перейти к нему можно через пункт
Терминал в меню Окна или через список окон (Окна > Список окон...).

В заголовке - каталог, в котором находится оболочка, и команда, которую она
выполняет.

Закрытие окна завершает оболочку. Если редактор распознал, что оболочка
выполняет команду, он запрашивает подтверждение при закрытии окна и при
выходе из редактора. После завершения оболочки, например по *exit*, Ctrl-O
запускает в окне новую.

**Клавиши**

Каждая клавиша, не названная ниже, передаётся оболочке, в том числе
функциональные клавиши и Esc, а также клавиши курсора, Home и End, которые
использует оболочка для редактирования команды и просмотра её истории.
Программа, которая переключилась на альтернативный экран терминала,
получает все клавиши, включая Ctrl-O. Меню и панель кнопок доступны мышью.

Терминал хранит до 5000 строк истории прокрутки. Длинные строки могут
сократить этот объём из-за ограничения на число ячеек. Клавиши курсора
с Shift выделяют вывод, начиная с места, где оболочка ждёт ввода.

|  |  |
|--|--|
| Ctrl-Insert, Enter, F2 | Скопировать выделенный вывод в файл обмена. Без выделения Enter передаётся оболочке |
| Ctrl-Shift-U | Снять выделение |
| Alt-s | Искать в выводе то, что набрано дальше |
| Alt-S | Показать только строки с тем, что набрано дальше |
| Ctrl-L | Очистить экран, оставив историю прокрутки |
| Ctrl-Shift-L, Ctrl-Alt-L, F6 | Очистить и экран, и историю прокрутки |
| Ctrl-Up, Ctrl-Down | Прокрутить вывод на одну строку |
| PgUp, PgDn | Прокрутить вывод на страницу |
| Ctrl-Home | К самой старой строке вывода |
| Ctrl-End | К самой новой строке вывода |
| F3 | Выделить весь вывод или снять выделение |
| F4 | Показать только строки с выделенным текстом или со словом под курсором |
| F5 | Выключить и снова включить этот фильтр |

Alt-s и Alt-S открывают в верхней строке окна поле ввода текста для поиска
или фильтрации. Результат обновляется по мере набора, регистр букв не
учитывается. Enter завершает ввод и оставляет результат на экране, Esc
отменяет ввод и возвращает прежний вид.

Клавиши можно переназначить в секции *[mcterm]* файла
*~/.config/bluerig/keymap.ini* или в диалоге Привязки клавиш меню Настройки.
Ctrl-O - действие *Shell* секции *[editor]*.

**Настройки**

Секция *[Terminal]* файла *~/.config/bluerig/ini* содержит настройки
терминала.

*window_height*
: Высота окна при первом показе, в процентах от рабочей области редактора.
От 10 до 100, по умолчанию 25.

*search_direction*
: Направление, в котором Alt-s и Alt-S проходят по выводу: down
(по умолчанию) или up, как в *less*.
