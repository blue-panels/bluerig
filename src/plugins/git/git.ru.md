# Git <!-- help:notitle -->

**Git**

Показывает изменения рабочего дерева git и коммиты ветки, добавляет файлы в
индекс, делает коммиты, amend и reword, push, pull и fetch. Сообщение коммита
пишется в окне редактора.

|  |  |
|--|--|
| Alt-C | Окно Git на вкладке Status |
| Alt-L | Окно Git на вкладке Log |

Клавиши меняются в секции *[git]* файла привязок клавиш. У команды GitCommit,
коммита того, что в индексе, из любого окна, клавиши по умолчанию нет; она
есть в меню Команда.

Рабочее дерево - дерево файла на переднем плане, иначе дерево проекта, иначе
дерево текущего каталога. Плагин запускает *git* системы, поэтому действуют
хуки, настройки и имя пользователя.

**Окно Git**

```
 ┌─[Сообщение коммита]────────────────┐┌─[Diff]────────────────┐
 │ сообщение                          ││ дифф файла            │
 │ следующего коммита                 ││ или коммита           │
 └────────────────────────────────────┘│                       │
 ╔═[ 1 Status ] [ 2 Log ] [ 3 Graph ]═╗│                       │
 ║ неиндексированные изменения        ║│                       │
 ╚════════════════════════════════════╝│                       │
 ┌─[Staged changes]───────────────────┐│                       │
 │ индексированные изменения          ││                       │
 └────────────────────────────────────┘└───────────────────────┘
```

Окна стоят рамка к рамке на месте окон файлов. В заголовке списка - ветка и
насколько она впереди своей upstream-ветки и позади нее. Закрытое окно
возвращает его пункт в меню Окна; Esc или F10 закрывает окно Git целиком, а
сообщение коммита остается до следующего раза.

|  |  |
|--|--|
| 1, 2, 3 | Вкладки Status, Log и Graph |
| Tab | Следующее окно: изменения, индекс, дифф |
| Right, Left | В дифф и обратно |
| F5, Ctrl-R | Перечитать все |
| F6 | git push |
| F7 | git pull |
| Shift-F5 | git fetch |
| Shift-F7, b | Ветки |
| F1 | Эта справка |
| Esc | Выйти из диффа или файлов коммита, иначе закрыть окно Git |
| F10 | Закрыть окно Git |

Статус перечитывается сам, когда окно выходит на передний план. В диффе Up,
Down, PgUp, PgDn, Home, End и Space прокручивают его, Right и Left - вбок.

Push, pull и fetch выполняются в окне терминала, чтобы git мог спросить там
пароль; после них все перечитывается. Без плагина Терминал git выполняется на
терминале редактора.

**Вкладка Status**

Неиндексированные изменения, включая файлы, которые git не отслеживает (*?*),
и изменения в индексе. Файл с конфликтом слияния помечен *U*.

|  |  |
|--|--|
| Enter, Space | Добавить файл в индекс или убрать из него |
| a | Добавить в индекс все или убрать все |
| F2, c | К сообщению коммита; F2 там делает коммит |
| F3, A | Исправить последний коммит (amend) |
| F4, e, r | Открыть файл в окне редактора |
| F8, d, Delete | Отменить изменения файла |

F8 спрашивает подтверждение: отслеживаемый файл возвращается к состоянию
индекса, а неотслеживаемый удаляется.

**Вкладка Log**

Коммиты ветки, новые сверху, с ветками и тегами; справа - автор, даты,
сообщение и файлы коммита. Коммиты читаются по 2000 по мере прокрутки.

|  |  |
|--|--|
| Enter | Файлы коммита; Enter на файле - его дифф |
| e | Открыть файл рабочего дерева |
| F4, r | Изменить сообщение коммита (reword) |
| Left, Esc | Назад к коммитам |

**Вкладка Graph**

Коммиты веток графом: каждая ветка в своем столбце, слева *main* или
*master*, *develop*, *release*, *hotfix*, затем остальные. Слияние - полый
узел. Enter, e, F4 и r работают как на Log; reword - только для коммитов
текущей ветки.

|  |  |
|--|--|
| v | Выбрать, какие ветки читать |

v предлагает *Current* (только HEAD), *Local* (локальные ветки и теги),
*Local+remote* (по умолчанию, еще и удаленные ветки) и *All* (все ссылки,
в том числе stash и *refs/pr/...*). Выбор сохраняется.

Линии графа - линии рамок скина. Секция *[git-graph]* скина задает свои
линии (ключи *[Lines]*), символы *commit*, *merge*, *arrow-left*,
*arrow-right*, *more* и *rail*, и цвета *main*, *develop*, *release*,
*hotfix* и *others* (через *;*):

```
[git-graph]
    commit = *
    merge = o
    rail = (
    others = magenta;cyan;brightmagenta;brightcyan
```

*rail* ставит коммит рядом с линией ветки, после этого символа.

**Ветки**

Локальные и удаленные ветки и, если отмечено, теги; сначала текущая, затем
по свежести последнего коммита. Набранные слова фильтруют список по имени,
автору и теме последнего коммита. *Extended* ищет еще и в сообщениях
собственных коммитов ветки.

|  |  |
|--|--|
| Enter | Переключиться на ветку (git switch) |
| F7 | Создать ветку от выбранной |
| F8 | Удалить локальную ветку |
| F3 | Сравнить с текущей веткой |
| Esc | Закрыть |

Удаленная ветка переключается через локальную с тем же именем, при этом
локальная создается, если ее нет. Тег переключается с отсоединенным HEAD. F8
спрашивает подтверждение, а для неслитой ветки спрашивает еще раз.

**Push**

F6 показывает ветку, удаленный репозиторий (пробел выбирает другой) и три
флажка:

|  |  |
|--|--|
| Force with lease | --force-with-lease; отмечен после amend или reword ветки, уже отправленной |
| Set upstream | -u; отмечен для ветки без upstream |
| Include tags | --follow-tags |

Принудительный push без lease не делается никогда. Если ветка разошлась с upstream по другой
причине, Force with lease не отмечен, и первая строка диалога говорит об
этом.

**Сообщение коммита**

Пишется в окне редактора, в файле *BLUERIG_EDITMSG* в каталоге git
(*BLUERIG_AMEND_EDITMSG* для amend, *BLUERIG_REWORD_EDITMSG* для reword).
Сохранение (F2) делает коммит. Если в индексе ничего нет, плагин сначала
предлагает добавить все. Строки с *#* отбрасываются; ниже них показано, что
коммитится.

Сообщение следующего коммита сохраняется при закрытии окна Git и выходе из
редактора. Amend или reword временно занимает его место. Если git отказал
(например, хук *commit-msg*), окно остается, чтобы сохранить еще раз.

Reword пересоздает коммит и коммиты после него, как *git rebase*, не трогая
индекс и рабочее дерево и не запуская хуки, при этом пересозданные коммиты
теряют подписи. Коммиту, после которого есть слияние, сообщение не меняется.

**Меню сообщения**

F11 в окне сообщения (и в *COMMIT_EDITMSG*, когда bluerig - редактор
*git commit*) открывает меню вместо меню пользователя. Ctrl-U отменяет то,
что сделал пункт.

|  |  |
|--|--|
| s | Signed-off-by с именем и почтой из git config |
| c | Co-authored-by с автором из истории |
| f | Fixes с выбранным коммитом |
| r | Вернуть текущее сообщение коммита (amend, reword) |
| d | Дифф коммита в окне справа |
| l | Проверить вид сообщения: длину темы, пустую вторую строку, строки длиннее 72 |
| g | Написать сообщение с помощью ИИ |
| p | Править промпт ИИ |
| m | Править это меню |

**git-menu.ini**

Меню берется из *~/.config/bluerig/git-menu.ini*, иначе из *git-menu.ini* в
*/etc/bluerig*. Пункт - группа, названная его клавишей:

```
[x]
label = Reviewed-by: a reviewer
command = echo 'Reviewed-by: A Reviewer <a@example.org>'
output = trailer
```

|  |  |
|--|--|
| label | Подпись в меню |
| action | Действие плагина: signoff, coauthor, fixes, restore, diff, check, generate, prompt, menu |
| command | Команда sh в рабочем дереве; сообщение идет ей на стандартный ввод |
| output | trailer, replace, insert (по умолчанию), show или none |
| modes | commit, amend, reword через ;, по умолчанию все |

Репозиторий меню не задает: его команды выполняли бы то, что написал автор
репозитория.

**ai.ini**

Команду, которая пишет сообщения, задает группа *[commit-message]* файла
*~/.config/bluerig/ai.ini*:

```
[commit-message]
command = claude -p --tools "" --no-session-persistence
input = diff
```

|  |  |
|--|--|
| command | Команда sh: читает промпт и дифф со стандартного ввода, печатает сообщение |
| prompt | Промпт; по умолчанию - промпт bluerig |
| prompt-<вид> | Промпт для commit, amend или reword |
| input | diff (по умолчанию) или none |

Команда получает в окружении *BLUERIG_GIT_MODE* (commit, amend, reword) и
*BLUERIG_GIT_COMMIT* (коммит для amend и reword). Значения читаются как
key-файлы GLib: обратная косая черта начинает escape-последовательность.

Файл *.bluerig/ai.ini* проекта задает свои промпты и input, но не команду.
Ключ доступа к сервису хранится в окружении или в файле, который читает
команда, но не в *ai.ini*. Дифф уходит тому сервису, который вызывает
команда.

**Запуск из файлового менеджера**

|  |  |
|--|--|
| bluerig -G каталог | Окно Git; F10 завершает редактор |
| bluerig -G каталог --git-log | То же, на вкладке Log |
| bluerig -G каталог --git-show коммит | То же, на файлах коммита |
| bluerig -G каталог --git-commit | Сообщение коммита; редактор завершается после коммита |
| bluerig -G каталог --git-amend | То же для amend |
| bluerig -G каталог --git-reword коммит | То же для reword |

С *-G* редактор не открывает окна проекта и не запускает плагины Файлы проекта,
Сборщик, Отладчик, Ctags и Etags.
