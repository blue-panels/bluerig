# Lekérdező box <a id="querybox"></a>

A lekérdező boxban a nyílbillentyűkkel vagy a gomb kiemelt betűjével válassza ki a gombot, és az Enterrel nyomja meg; a gombra kattintás is megnyomja. Az Esc válasz nélkül bezárja a boxot.

# Hogyan használjuk a súgót <a id="how-to-use-help"></a>
<a id="help"></a>

A súgó szinte bárhol az F1 billentyűvel nyílik meg. A súgóablakban a kurzorbillentyűkkel vagy az egérrel mozoghat. A **lefelé nyíl** a következő linkre lép, vagy lefelé görget. A **felfelé nyíl** az előző linkre lép, vagy felfelé görget. A **jobbra nyíl** vagy az **Enter** követi az aktuális linket. A **balra nyíl** visszalép a meglátogatott pontok előzményeiben.

Ha a terminál nem ismeri a kurzorbillentyűket, a **szóköz** előre, a **b** billentyű visszafelé görget. A **Tab** a következő linkre lép, az **Enter** követi azt. Az **l** billentyű visszalép a meglátogatott pontok előzményeiben. Az **Esc** kilép a súgóból.

A bal egérgomb követi a linket, vagy görget. A jobb egérgomb visszalép a pontok előzményeiben.

A keret jobb oldalán lévő sáv mutatja, hol tart a képernyő a pontban: egy nyíl egy sort görget, a csúszka melletti kattintás egy oldalt, a csúszka pedig húzható.

A súgóablak összes billentyűje:

Az [általános mozgatóbillentyűk](#general-movement-keys) is működnek.

```
Tab             a következő linkre
Alt-Tab         az előző linkre
Down            a következő link, vagy egy sor görgetése lefelé
Up              az előző link, vagy egy sor görgetése felfelé
Right, Enter    az aktuális link követése
Left, l, F3     vissza a meglátogatott pontok előzményeiben
F1              a súgó használatának súgója
n               a következő pontra
p               az előző pontra
c, F2           a tartalomjegyzékre
F10, Esc        kilépés a súgóból
```
